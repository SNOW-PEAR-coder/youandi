# 姻缘判法

供 `youandi` 在写解读前读取。脚本负责「算什么」，本文负责「怎么断」。

## 1. 取用基准

- **男命以财星为妻星**：正财＝正妻、稳定关系；偏财＝偏缘、恋爱对象、也会应「妻有活钱或副业」。
- **女命以官杀为夫星**：正官＝正夫；七杀＝偏缘、强势对象。官杀混杂主选择反复。
- **日支为夫妻宫。** 年柱主长辈与远方，月柱主父母与成长环境，日支主配偶本人，时柱主子女与晚年。
- 十神一律以日干为我，脚本已算好，直接引用。

## 2. 妻星／夫星五看

1. **透与藏。** 透干＝缘显（易见、易公开、有明确对象）；只藏支＝缘隐（暗恋、慢热、异地、不便公开）。
2. **位置。** 年柱＝早、远、常由长辈介绍；月柱＝近、同辈圈；日支＝婚姻本体；时柱＝晚、子女宫、易应老少配。
3. **坐支。** 坐天乙贵人／金舆＝配偶有福有助；坐墓库＝财入墓，感情藏而不发、聚散反复；坐劫财羊刃＝易被分夺。
4. **旺衰与源流。** 有食伤生财＝财源不断、配偶能干；被比劫克＝竞争、破财、第三者介入；财星有根通月令＝关系扎实。
5. **喜忌。** 日主旺则财为用，能得配偶之助；日主弱而财多，反为财所累、婚姻带来压力。冬生之土需火暖，水财虽为用亦带寒气，需自身「火」（行动力、热情）配合才能焐热——这是「能不能得妻财」的关键门槛。

## 3. 夫妻宫五看

1. **日支十神。** 食神＝聪慧温和有才艺；伤官＝有才气有个性、易挑剔；正财＝务实持家；偏财＝会赚活钱；正官＝端正自律；七杀＝强势；正印＝慈厚；偏印＝孤僻多思；比肩＝自我；劫财＝竞争。
2. **刑冲合害。** 逢冲＝婚姻动荡、异地、聚少离多；逢合＝有情但易受牵制；逢害＝暗中消耗、猜疑；逢刑＝口舌折磨。**伏吟＝反复，旧模式重演。**
3. **空亡。** 夫妻宫或配偶星落空亡，主缘薄、事缓、有名无实、易有缘无份。
4. **神煞**（见第 4 节）。
5. 日支被三合／半合所化之五行，是否反过来引动财官。

## 4. 神煞专论

| 神煞 | 姻缘含义 |
|---|---|
| 天乙贵人 | 配偶为贵人，得配偶或其家庭之助 |
| 金舆 | **男命「因妻得财」最直接的星**，主荫妻之福、配偶有福气 |
| 红鸾、天喜 | 婚喜应期。流年逢之常应恋爱、订婚、结婚 |
| 桃花（咸池） | 异性缘。年月＝早年缘显；日时＝中年后与晚年，或子女宫桃花。需逢合逢冲才真正动 |
| 孤辰、寡宿 | 孤独、迟婚、夫妻有距离感。**落夫妻宫最应验** |
| 红艳煞 | 多情、魅力强、易惹情事 |
| 阴差阳错日 | 与姻亲（岳家／婆家）缘薄，婚事多波折。**会折损金舆之利** |
| 驿马 | 主奔波异地。驿马冲夫妻宫，多应异地恋或聚少离多 |

## 5. 应期取法

应期看「**引动**」，不看吉凶。任一条成立即为感情事件窗口：

1. 配偶星（男看财、女看官杀）透干或临旺地之年。
2. 流年支与夫妻宫构成六合、六冲、半合、暗合、六害之年。
3. 流年逢红鸾、天喜、桃花、驿马之年。
4. 流年与原局日柱相同（**伏吟**）＝关系翻新或换人。
5. 大运与流年同支（**岁运并临**）＝事件密集、力量加倍。
6. 交运前后一两年常有人生转折，含婚恋。

**强度排序**（给用户排先后时用）：配偶星成局（如申子辰会水）＋夫妻宫逢合 ＞ 红鸾天喜 ＞ 单纯配偶星透干 ＞ 单纯桃花。

## 6. 婚姻迟速

**偏迟的信号**（越多越迟）：孤辰寡宿、阴差阳错日、夫妻宫带比劫、配偶星坐墓、夫妻宫空亡、配偶星藏而不透且无生扶。
**偏早的信号**：配偶星透干通根、夫妻宫合日主、红鸾天喜临夫妻宫。

表述用「偏迟／偏早」并给出应期窗口，**不要断言具体岁数**。

## 7. 配偶画像取法

- **五行与性格**：以配偶星五行配合夫妻宫十神并参。
- **方位**：看配偶星所落柱位（年柱主远方）与五行所属方位。
- **生肖宜忌**：以年支的三合六合为喜，六冲三刑为忌。
- **职业倾向**：以夫妻宫十神与五行取象，只作方向性描述，不作职业断言。

## 8. 合婚要点

1. 双方用神是否互补（一方所喜正是另一方所长）。
2. 两人日支是否相合，有无冲刑害。
3. **生肖只作参考，不作定论。**
4. 各自夫妻宫的神煞与刑冲，比生肖重要得多。

## 9. 常见误区

- 只用生肖合婚。
- 忽略真太阳时，导致时柱错、整篇偏。
- 用农历年替代立春换年。
- 把「桃花」直接等同于出轨或婚姻不顺。
- 见到孤辰寡宿就断独身。
- 把「应期」说成「必然发生」。

## 10. 边界

命理是传统文化参考，不作健康诊断、生死预测、投资与法律建议。生辰属个人敏感信息，不主动索取第三方八字，不外传。措辞用「倾向」「较容易」「可留意」，避免绝对化。
